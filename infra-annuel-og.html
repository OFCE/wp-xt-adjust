L’écart de production infra-annuel : calibrer l’invariance par la moyenne annuelle

Cette note dérive la calibration du bloc infra-annuel de l’écart de production (dwrsm3g) pour la cible retenue : l’invariance par la moyenne annuelle. C’est le pendant, pour une variable de niveau, du traitement « ratio de deux sommes » appliqué aux soldes : la moyenne des n valeurs mensuelles d’une année doit reproduire exactement la valeur du modèle annuel dwrsm3, pour tout profil de flux exogènes. Le modèle et sa sémantique sont décrits dans infra-annuel ; le diagnostic de la dynamique actuelle (oscillation parasite) y est résumé. Tous les chiffres de cette note sont reproduits par le script de la dernière section.

1 La cible et son périmètre

Définition (invariance par la moyenne). Notons \bar{og}_y la moyenne des valeurs mensuelles de l’année y et D_y les flux annuels (demande : multiplicateurs × impulsions budgétaires). La calibration doit garantir, pour toute trajectoire \{D_y\} et tout historique (og_0, og_{-1}) :

\bar{og}_y \;=\; og^{\text{annuel}}_y \qquad \text{pour tout } y,

où og^{\text{annuel}}_y suit la récurrence de dwrsm3 alimentée par les mêmes flux. La cible « moyenne » est cohérente avec l’agrégation retenue pour og dans le tibble annuel (groupe mean de .dwr.agg), et avec la lecture économique de dwrsm3 : og_y est une valeur d’année, pas un instantané de décembre.

La calibration comporte quatre objets : (i) les coefficients de la récurrence mensuelle, (ii) le noyau d’injection des flux, (iii) la carte d’état initial, (iv) l’échelle du bruit. Le périmètre est le bloc linéaire de og ; restent hors périmètre les canaux mensuel-natifs (og_cin, pot_r), les couplages non linéaires (multiplicateurs variables, Okun, Phillips) et les lecteurs d’états de décembre — voir Portée et limites.

2 Le système annuel de référence

En production (siminit2.R), og_lag = L = 0{,}1, og_mce = C = 0{,}4 et og_ddpot = 0. La récurrence annuelle s’écrit :

\Delta og_t = L\,\Delta og_{t-1} - C\,og_{t-1} + D_t .

En représentation d’état (og, \Delta og), les racines de la dynamique libre résolvent \lambda^2 - (1+L-C)\lambda + L = 0, soit \lambda = \{0{,}5\,;\,0{,}2\} : décroissance monotone, la moitié de l’écart résorbée en un an. La réponse à un flux unitaire (le flux entre dans \Delta og) est

H_k = A\,\lambda_1^k + B\,\lambda_2^k, \qquad A = \tfrac{5}{3},\; B = -\tfrac{2}{3},

soit H_0 = 1, H_1 = 0{,}70, H_2 = 0{,}39… et un gain statique \sum_k H_k = 1/C = 2{,}5 : un flux soutenu D maintient og à D/C.

3 Les deux objets de calibration du modèle mensuel

dwrsm3g conserve la forme structurelle au pas 1/n (n = 12) :

og_m = (1+\text{mom}-\text{ecm})\,og_{m-1} - \text{mom}\,og_{m-2} + d_m, \qquad d_m = w_m\,D_y ,

où (\text{mom}, \text{ecm}) sont les coefficients mensuels et w le noyau qui distribue le flux annuel. Ce sont deux objets indépendants, et le modèle actuel échoue sur les deux :

  • Coefficients factoriels. Le momentum \text{mom} = L^{1/n} est correct (produit des racines mensuelles), mais l’ECM \text{ecm} = 1-(1-C)^{1/n} n’est exact que si L = 0. Avec L = 0{,}1, la récurrence mensuelle a des racines complexes 0{,}892 \pm 0{,}173i (oscillation amortie de période 33 mois), qui échantillonnées en décembre donnent -0{,}21 \pm 0{,}24i : même aux frontières d’année, la dynamique n’est plus celle de dwrsm3.
  • Noyau janvier. Même à L = 0 (AR exact), le noyau neutre is_jan sous-livre la réponse moyenne : 0{,}7998 en année 1, 0{,}80 en gain statique. Un facteur \kappa = n(1-\mu)/(1-\mu^n) = 1{,}2503 le corrige alors exactement. À L = 0{,}1, les deux erreurs se compensent partiellement : la réponse moyenne de l’année vaut 2{,}24 fois l’annuel en année 0, puis bascule de signe (tableau ?@tbl-ir).

4 Théorie de l’invariance par la moyenne

4.1 Dynamique libre : appariement des racines

Proposition 1. Soit le chemin mensuel libre og_m = c_1\mu_1^m + c_2\mu_2^m. La suite de ses moyennes annuelles satisfait la récurrence annuelle si et seulement si \mu_i^n = \lambda_i, c’est-à-dire \mu_i = \lambda_i^{1/n}.

La moyenne de l’année y vaut en effet c_1\varphi(\mu_1)\mu_1^{n(y-1)} + c_2\varphi(\mu_2)\mu_2^{n(y-1)} avec \varphi(\mu) = \frac{1}{n}\sum_{m=1}^{n}\mu^m : une combinaison des modes \mu_i^n, dont les racines appariées font exactement les racines annuelles. D’où les coefficients :

\text{mom} = L^{1/n}, \qquad \text{ecm} = 1 + L^{1/n} - \sum_i \lambda_i^{1/n}

(en racines complexes conjuguées : \text{ecm} = 1 + L^{1/n} - 2|\lambda|^{1/n}\cos(\theta/n)). La formule retombe sur l’actuelle 1-(1-C)^{1/n} si et seulement si L = 0 — d’où l’insensibilité du bloc prix, où inf_lag = 0 en production. À n = 1 : \text{ecm} = C, \text{mom} = L, l’identité V0 est préservée par construction.

NotePourquoi L^{1/n} et non L^{1/n^2}

Chacune des deux racines porte bien un facteur 1/n, mais le produit se réduit comme L^{1/n} et non L^{1/n^2} : \mu_1\mu_2 = \lambda_1^{1/n}\lambda_2^{1/n} = (\lambda_1\lambda_2)^{1/n}, les exposants s’ajoutant en log quand les racines se multiplient — L^{1/n^2} supposerait les deux réductions composées en série, alors que les modes agissent en parallèle.

Nombres : \lambda = \{0{,}5\,;\,0{,}2\}, \mu = \{0{,}94387\,;\,0{,}87449\}, mom = 0{,}82540 (inchangé) et ecm = 0{,}00704, contre 0{,}04168 actuellement — l’ECM mensuelle est aujourd’hui 5{,}9 fois trop forte.

4.2 Flux : trois conditions de moments

La réponse du niveau mensuel à une unité de flux injectée au mois 0 est g_0 = 1 puis la décroissance libre : g_\ell = P\mu_1^\ell + Q\mu_2^\ell avec P = \frac{\mu_1}{\mu_1-\mu_2}, Q = -\frac{\mu_2}{\mu_1-\mu_2}. Cette IR est une bosse : pic \approx 4{,}4 vers 10 mois, gain statique 1/\text{ecm} \approx 142 par unité mensuelle — contre 2{,}5 par unité annuelle. C’est pourquoi « répartir le flux annuel sur les mois » sur-livre massivement la moyenne.

Notons G_{k,j} la réponse de la moyenne de l’année k à une unité injectée au mois j de l’année 0 (somme sur la fenêtre de l’IR divisée par n, pas par la longueur de la fenêtre) :

G_{k,j} = \frac{1}{n}\sum_{\ell} g_\ell, \qquad \ell \in [kn+1-j,\ (k+1)n-j] \ \text{(et } \ell \ge 0\text{)} .

Proposition 2. L’invariance de la réponse aux flux, pour toute trajectoire \{D_y\}, équivaut aux trois conditions \langle w, G_0\rangle = 1, \langle w, G_1\rangle = H_1, \langle w, G_2\rangle = H_2.

Esquisse. Pour k \ge 1, les fenêtres évitent \ell = 0 et G_{k,j} = \alpha_j\lambda_1^k + \beta_j\lambda_2^k : les lignes k \mapsto G_{k,\cdot} obéissent à la récurrence annuelle dès k = 3 (vérifié numériquement à 10^{-15}). Égaler k = 1, 2 fixe les deux fonctionnelles modales, donc tous les k \ge 1 ; la ligne k = 0, qui contient le terme g_0, est indépendante (rang 3 vérifié) et fournit la troisième condition. ∎

Les solutions forment un espace affine de dimension n - 3. Deux choix canoniques donnent des filtres quasi confondus — la projection de l’uniforme sur les contraintes, et l’unique noyau quadratique (figure graphique 1) :

w = (0{,}186,\ 0{,}130,\ 0{,}077,\ 0{,}030,\ -0{,}011,\ -0{,}044,\ -0{,}065,\ -0{,}074,\ -0{,}067,\ -0{,}041,\ 0{,}008,\ 0{,}084)

Trois lectures :

  • Le profil de livraison G_{0,j} décroît de 3{,}405 (janvier) à 0{,}083 (décembre) : un mois d’avance « pèse » 41 fois plus dans la moyenne de l’année.
  • La masse totale est épinglée : \sum_j w_j = n \cdot \text{ecm} / C = 0{,}2113 (identité de gain statique : en régime périodique, la traînée ECM équilibre exactement les injections). Le noyau n’est donc pas une distribution de timing — c’est un filtre correcteur, avec des poids négatifs en cours d’année pour annuler la sur-livraison de la bosse.
  • Pas de raccourci simple : l’uniforme recalibré sur H_0 seul (\kappa = 0{,}64) laisse un écart de 0{,}198 sur le test de trajectoire — le mélange modal compte, les trois conditions sont nécessaires.

4.3 État initial : carte modale

Proposition 3. Si l’état mensuel initial (og_{\text{déc}}, og_{\text{nov}}) est fixé par c_i = a_i \mu_i^n / \varphi(\mu_i), où (a_1, a_2) sont les coordonnées modales annuelles de (og_0, og_{-1}), la partie libre des moyennes annuelles reproduit exactement la décroissance libre annuelle.

La carte est linéaire (lignes : décembre, novembre ; colonnes : og_0, og_{-1}) :

\begin{pmatrix} og_{\text{déc}} \\ og_{\text{nov}} \end{pmatrix} = \begin{pmatrix} 0{,}9022 & -0{,}0943 \\ 0{,}9317 & -0{,}0879 \end{pmatrix} \begin{pmatrix} og_0 \\ og_{-1} \end{pmatrix}

Elle remplace l’initialisation actuelle (valeurs annuelles brutes passées comme retards mensuels), qui n’est correcte pour aucun des deux alignements (décembre ou moyenne).

4.4 Bruit : appariement des variances

Le brit mensuel (innovations indépendantes, ogn_ar = 0 en production) injecte chaque mois un flux ogn_sigma · og_mce · k_ogn. La variance de la composante de bruit de la moyenne annuelle est \sigma_m^2 \sum_{k,j} G_{k,j}^2, celle du modèle annuel \sigma_a^2 \sum_k H_k^2.

Proposition 4. L’appariement des variances donne k = \sqrt{\sum_k H_k^2 / \sum_{k,j} G_{k,j}^2}, soit k_ogn = 0{,}0666 — contre \approx 0{,}37 pour la cible « frontière d’année » actuellement calibrée par sub_noise_factors(). Le compromis est structurel : sous la cible moyenne, la variance de décembre n’est plus épinglée.

7 Portée et limites

  • Couplages linéaires : la somme \sum_m \text{dep\_og} \cdot og_{m-1} dans dep_prim vaut n \cdot \bar{og}_y moins le terme de frontière (og_{\text{déc},y} - og_{\text{déc},y-1}) — invariance exacte en régime établi, écart résiduel d’ordre un en transition.
  • Couplages non linéaires : multiplicateurs variables (og_rcn, fonction de lagog), Okun (tcho_okun · dog), Phillips : ils lisent des valeurs mensuelles qui varient de ±18 % autour de la moyenne — écarts de type Jensen, du second ordre tant que l’amplitude intra-année reste modérée.
  • Lecteurs de décembre : la valeur de décembre vaut -19\ \% de la moyenne en régime établi. La règle, qui lit lagog de décembre, verrait donc un og non conforme à la sémantique annuelle. Recommandation : engager en décembre un état « moyenne de l’année close » (mécanique identique à lagspp) et le faire lire par la règle.
  • Canaux mensuel-natifs : og_cin et pot_r ont des entrées réellement mensuelles (r_inst) ; leur cohérence annuelle est une question distincte (c’est aussi le canal de l’effet boule de neige des intérêts).
  • Noyau fourni par l’utilisateur : un mkern exprimant un scénario de timing doit être projeté sur les trois contraintes (w = s - M^\top(MM^\top)^{-1}(Ms - h)) — la convention « somme à 1 » disparaît. Le noyau calibré devient le neutre par défaut.
  • Bruit : les facteurs k sont à rédériver canal par canal pour la cible moyenne (formule de la proposition 4) ; la calibration « frontière » actuelle ne s’applique plus.

8 Implémentation et validation

  • dust_fix_params() calcule et injecte : l’ECM mensuelle appariée, le noyau neutre w, la carte d’état initial appliquée à i_lagog/i_lag2og, et k_ogn (cible moyenne).
  • Dans le modèle : kern prend la valeur w par défaut ; mkern_use = 1 projette la forme fournie ; l’ECM mensuelle devient paramétrable (la dérivation interne reste en repli).
  • À n = 1 tout retombe sur dwrsm3 (\text{ecm} = C, \text{mom} = L, w = 1, k = 1) : la V0 est inchangée par construction.
  • Nouvelle passe de validation (V1-moyenne) : égalité des moyennes annuelles dwrsm3g vs dwrsm3 sous baseline, impulsions et flux aléatoires, règle coupée (tolérance ~10^{-12}), puis boucle fermée — les écarts résiduels y seront attribuables aux choix documentés ci-dessus (lecteurs de décembre, non-linéarités), plus à une vraie question de design.

9 Script de référence

library(tidyverse)

n <- 12; L <- 0.1; C <- 0.4
lam <- sort(Re(polyroot(c(L, -(1 + L - C), 1))), decreasing = TRUE)
mu <- lam^(1/n)
mom <- L^(1/n)
ecm <- 1 + mom - sum(mu)                    # ECM appariée aux racines annuelles

P <- mu[1] / (mu[1] - mu[2]); Q <- -mu[2] / (mu[1] - mu[2])
g_ir <- function(l) P * mu[1]^l + Q * mu[2]^l    # IR mensuelle du flux unitaire

# G_{k,j} : réponse de la moyenne de l'année k à une unité injectée au mois j
G_row <- function(k) vapply(seq_len(n), function(jj)
  sum(g_ir((k * n + 1 - jj):((k + 1) * n - jj))) / n, numeric(1))
G0 <- vapply(seq_len(n), function(jj) sum(g_ir(0:(n - jj))) / n, numeric(1))
Gk <- function(k) if (k == 0) G0 else G_row(k)
M <- rbind(G0, G_row(1), G_row(2))           # trois conditions de moments
h <- c(1, 1 + L - C, (1 + L - C)^2 - L)      # H_0, H_1, H_2

u <- rep(1 / n, n)
w <- as.numeric(u - t(M) %*% solve(M %*% t(M), M %*% u - h))  # projection de l'uniforme
sum(w)                                       # = n * ecm / C

phi <- (mu / n) * (1 - mu^n) / (1 - mu)      # carte d'état initial
init <- function(og0, ogm1) {
  a <- solve(rbind(c(1, 1), c(1 / lam[1], 1 / lam[2])), c(og0, ogm1))
  cc <- a * mu^n / phi
  c(dec = sum(cc), nov = sum(cc / mu))
}

# vérification : trajectoires annuelle vs mensuelle calibrée
set.seed(7341); ny <- 30
Dy <- rnorm(ny, sd = 0.03); og0 <- 1; ogm1 <- 0.8
og_ann <- numeric(ny); x1 <- og0; x2 <- ogm1
for (y in seq_len(ny)) {
  og_ann[y] <- (1 + L - C) * x1 - L * x2 + Dy[y]; x2 <- x1; x1 <- og_ann[y]
}
st <- init(og0, ogm1)
og_m <- numeric(ny * n); l1 <- st[["dec"]]; l2 <- st[["nov"]]
for (y in seq_len(ny)) for (m in seq_len(n)) {
  cur <- (1 + mom - ecm) * l1 - mom * l2 + w[m] * Dy[y]
  og_m[(y - 1) * n + m] <- cur; l2 <- l1; l1 <- cur
}
max(abs(colMeans(matrix(og_m, nrow = n)) - og_ann))   # ~1e-15 : invariance exacte

# facteur de bruit (cible : variance de la moyenne annuelle)
A <- (1 + L - C - lam[2]) / (lam[1] - lam[2]); B <- 1 - A
sumH2 <- sum(sapply(0:300, function(k) (A * lam[1]^k + B * lam[2]^k)^2))
sumG2 <- sum(sapply(0:300, function(k) sum(Gk(k)^2)))
sqrt(sumH2 / sumG2)                          # k_ogn
